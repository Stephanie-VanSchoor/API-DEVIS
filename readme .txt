# 📄 API Devis - Template

## Qu'est-ce que c'est ?

Une API qui extrait automatiquement les données des devis :
- Numéro de devis
- Fournisseur
- Date
- Total HT
- TVA
- Total TTC

## Comment l'utiliser ?

1. Envoyer un devis à `/extraire`
2. Recevoir les données structurées
